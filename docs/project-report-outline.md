# Project Report Outline

Use this outline for the final Lab 6 report. Add your own name, ID, course details, figures, screenshots, test output, and repository URLs.

1. **Introduction**
   - Project background and problem statement
   - Objectives and scope
   - Intended users
2. **Requirements Analysis**
   - Functional requirements
   - Non-functional requirements
   - User stories and use cases
3. **Process Model**
   - Incremental model description
   - Justification
   - Planned and completed increments
4. **System Design**
   - Architecture and module descriptions
   - Prototype screenshots
   - UML class diagram
   - Three design patterns: problem, implementation, reason, rejected alternative
5. **Implementation**
   - Technology stack
   - Database schema and persistent storage
   - Screenshots of the six modules
   - Swagger/OpenAPI documentation
6. **Software Testing**
   - TDD examples showing Red, Green, Refactor evidence
   - Unit tests and API tests
   - Mock/fake dependencies
   - Selenium test
   - Actual coverage summary
   - GitHub Actions CI result
7. **Configuration Management**
   - Repository structure
   - Branch naming and commit history
   - Accepted PR and review
   - Revised/rejected PR and review
   - Merge conflict and resolution
8. **Self-Directed Learning**
   - New tool: Swagger/OpenAPI
   - Reason for choosing it
   - Resources and evaluation
   - Challenges and solutions
9. **Learning Log**
10. **Reflection Essay (500–700 words)**
11. **Conclusion and Future Plan**
12. **References**
   - Official documentation and learning resources actually consulted
